# 玩客云（OneCloud S805）ImmortalWrt 25.12 在线升级固件

**核心价值：刷一次，以后升级不用再拆机。** 不用双公头线，不用 USB Burning Tool，联网一条命令即可。

---

## 一、首次刷机（只需做一次）

首次仍要走线刷，用本仓库 Release 里的 `*.burn.img.xz`。

基本流程（详细步骤随包附带）：

1. 装 Amlogic USB Burning Tool，导入 `*.burn.img.xz`
2. 双公头 USB：一头接电脑，一头接玩客云**靠近 HDMI 的那个 USB 口**
3. 让设备进入刷机模式（拆机短接，或按住 reset 键再插电），工具识别到设备后松开
4. 点开始烧录，约 4-6 分钟
5. 烧录完成：先点**停止** → 拔电源 → **拔掉 USB 线**

第 5 步的拔线不能省，否则下次开机会反复进入刷机模式。

## 二、刷完之后怎么连

出厂默认：

| 项目 | 值 |
|---|---|
| 管理地址 | `172.16.8.1` |
| 用户名 | `root` |
| 密码 | 空（无密码） |
| LuCI | `http://172.16.8.1` |
| SSH | `ssh root@172.16.8.1` |

因为是固定 IP，第一次连接建议把电脑网口设为同网段（如 `172.16.8.2 / 255.255.255.0`），直连玩客云网口。也可以把玩客云接在上级路由下，用上级路由分配给它的 IP 地址连接，具体地址到路由器后台的已连接设备里查。

首次进入 LuCI 会提示设置密码，任意密码即可进入；SSH 空密码直接可登。

## 三、在线升级怎么用

升级命令已内置在固件里，登录后直接敲。

### 第一步：预检（推荐，不动系统）

```sh
upgrade --check
```

- 有新版：显示本机版本和目标版本
- 已是最新：直接退出，**不下载任何东西**
- 只读检查，不修改系统

### 第二步：正式升级

```sh
upgrade --reboot
```

它会自动完成：

1. 去本仓库的 Release 找最新版
2. 下载 rootfs（约 160MB）和 boot（约 5MB）
3. 检查 `/opt` 剩余空间是否够
4. 备份当前 `/etc/config`、`rc.local`、`shadow` 和 boot 分区
5. 解包替换系统文件
6. 写入新 boot
7. **约 10 秒后自动重启**

全程不需要人工操作，也不用拆机。下载走 GitHub，国内网络慢的话耐心等，脚本自带镜像重试。

### 全部参数

| 命令 | 作用 |
|---|---|
| `upgrade --check` | 只检查有没有新版 |
| `upgrade --reboot` | 升级并自动重启 |
| `upgrade --check --force` | 忽略版本比较，强制检查 |
| `upgrade --reboot --force` | 强制重刷当前版本（系统坏了想重装时用） |
| `upgrade --url=<地址>` | 手动指定 rootfs 包的下载地址 |

## 四、升级会不会丢配置

**有概率会，但一般情况下不会。** 升级是整体替换系统文件，`/etc/config` 下的设置（WiFi、插件配置、端口映射等）在个别情况下会恢复为出厂默认。

升级脚本会自动把原配置备份到：

```
/opt/upgrade-backup-<时间戳>/
```

升级完如果发现配置没了，可以这样恢复：

```sh
# 看看有哪些备份
ls -d /opt/upgrade-backup-*

# 恢复全部配置（把 <时间戳> 换成实际的）
cp -a /opt/upgrade-backup-<时间戳>/config/* /etc/config/

# 或者只恢复某一项，比如网络
cp -a /opt/upgrade-backup-<时间戳>/config/network /etc/config/

reboot
```

建议只恢复你真正需要的文件。跨版本恢复全部旧配置有时会因为配置项变化导致服务起不来。

## 五、出问题怎么办

**升级中途断电或断网**

系统会停在半新半旧的状态，系统内没法修复，只能重新线刷（回到第一节）。

**升级后开不了机**

用线刷包重新刷（回到第一节）。线刷是最彻底的恢复手段，刷完配置是出厂状态。

**报错说空间不足**

脚本会告诉你需要多少、实际剩多少。两个办法：

```sh
# 办法一：清理 /opt 下的大文件
du -sh /opt/* | sort -h

# 办法二：释放 ext4 保留块（约 45MB，一次性永久生效）
opkg install e2fsprogs && tune2fs -m 0 /dev/mmcblk1p2
```

**提示无法确定最新 Release**

检查设备能不能上网：

```sh
ping -c 3 github.com
```

如果域名不通但 IP 通，多半是 DNS 问题，检查 `/etc/config/dhcp` 里的 DNS 设置。

## 六、版本标识怎么看

Release 的 TAG 格式：

```
OneCloud_openwrt-25.12_26.11.01_10.39.54
                                 └─ 构建时间（北京时间）
```

设备内部的版本记录在 `/etc/oc-version`，内容形如 `26.11.01_10.39.54`。

`upgrade --check` 就是拿这个文件跟最新 Release 的 TAG 比对，完全一致就判定"已是最新"。

查看本机版本：

```sh
cat /etc/oc-version
```
